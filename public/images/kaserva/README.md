# Kaserva Logo Kit

Paket ini berisi variasi logo Kaserva untuk kebutuhan digital dan cetak.

## Isi paket

- `kaserva-logo-primary.png` — logo horizontal berwarna untuk header, landing page, dan dokumen.
- `kaserva-logo-stacked.png` — logo vertikal untuk ruang yang lebih persegi.
- `kaserva-mark.png` — simbol tanpa tulisan untuk avatar dan elemen UI.
- `kaserva-logo-monochrome-navy.png` — versi satu warna untuk struk, stempel, dan cetak sederhana.
- `kaserva-logo-reversed-white.png` — versi putih transparan untuk latar berwarna gelap.
- `kaserva-app-icon.png` — ikon persegi untuk aplikasi atau PWA.
- `favicon-512.png`, `favicon-192.png`, `favicon-32.png`, dan `favicon.ico` — ikon website dalam beberapa ukuran.

## Warna utama

- Navy: `#00204B`
- Teal: `#00A98F`

## Pedoman singkat

- Gunakan logo utama pada latar putih atau terang.
- Gunakan logo putih pada latar navy, hitam, atau foto gelap.
- Gunakan versi monokrom untuk printer struk dan media yang hanya mendukung satu warna.
- Sisakan ruang kosong di sekeliling logo minimal setara tinggi huruf `K` pada wordmark.
- Jangan mengubah proporsi, memiringkan, menambahkan bayangan, atau mengganti warna secara sembarangan.
